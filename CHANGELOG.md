# Changelog

## 1.0.0

- First release for Zotero 8, 9 and 10.
- Citation counts from OpenAlex (batched DOI lookup, API key support) and Semantic Scholar (batch API, optional key).
- Exact-title fallback for items without DOI or arXiv ID.
- Two sortable columns; counts stored in the Extra field so they sync.
- Item and collection context menus: update, update outdated only, remove, stop.
- Optional automatic fetch for newly added items.
- Zotero 10: each update is a single undo step.
- English and Simplified Chinese.
